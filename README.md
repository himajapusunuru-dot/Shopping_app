Developed an ecommerce Android application using Kotlin 
and MVVM architecture. The UI communicates with ViewModels, 
ViewModels interact with repositories, and repositories 
manage remote and local data sources. I used Retrofit with 
coroutines for REST API communication, Room for cart persistence,
 SharedPreferences for session management, LiveData with UiState
 for observing API states, RecyclerView with ListAdapter 
and DiffUtil for lists, Navigation Component for screen 
navigation, and ViewPager2 with a shared ViewModel 
for the checkout flow
